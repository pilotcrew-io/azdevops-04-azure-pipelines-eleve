# Atelier 04 — CI/CD Java avec Azure DevOps Pipelines

**Durée : 265 minutes (4 h 25), pauses comprises.** Prérequis à réaliser avant la séance.
Public : développeurs débutants ayant les bases Git, terminal et HTTP. Cet atelier est autonome ;
il ne dépend d'aucun autre atelier ni d'un ancien artefact.

Édition **élève — publique** du dépôt
`pilotcrew-io/azdevops-04-azure-pipelines-eleve`. Les noms désignent les dépôts cibles ; ce livrable ne les publie pas.
